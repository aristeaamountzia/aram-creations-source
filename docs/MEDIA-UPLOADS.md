# Μεταφόρτωση εικόνων και βίντεο

Η προετοιμασία γίνεται στον browser πριν χρησιμοποιηθούν οι υπάρχουσες μεταφορτώσεις Firebase Storage. Δεν απαιτείται νέο API key ή υπηρεσία μετατροπής.

- Εικόνες: αρχικό έως 30 MB. Έλεγχος πραγματικής υπογραφής, αποκωδικοποίηση και κοινή προετοιμασία για Shop/Portfolio. Η επέκταση και το MIME που δηλώνει η συσκευή δεν αρκούν από μόνα τους.
- JPEG, PNG, WebP, AVIF, BMP, ICO και SVG χρησιμοποιούν την αποκωδικοποίηση του browser. Τα SVG μετατρέπονται σε στατική JPEG. TIFF, PSD και JPEG 2000 χρησιμοποιούν εναλλακτική αποκωδικοποίηση FFmpeg όταν χρειάζεται. Οι πολυεπίπεδες εικόνες εισάγονται ως μία τελική εικόνα.
- HEIC/HEIF: το libheif διαβάζει την κύρια εικόνα σε ξεχωριστό worker· στη συνέχεια εφαρμόζονται τα υπάρχοντα όρια διαστάσεων/ποιότητας κάθε καταλόγου.
- GIF, APNG και κινούμενα WebP/AVIF διατηρούν τα αρχικά bytes και το σωστό MIME, αφού επιβεβαιωθεί ότι ανοίγουν. Δεν περνούν από canvas που θα αφαιρούσε την κίνηση.
- Βίντεο: αρχικό έως 1 GB / 10 λεπτά, τελικό έως 30 MB. Γίνεται μετατροπή σε MP4/H.264/AAC. Ο ήχος παραμένει· το Hero μπορεί να ζητήσει ρητά αφαίρεσή του.
- Οι συνηθισμένοι τύποι MP4/M4V/MOV, WebM, MKV, AVI, OGG, 3GP, MPEG, MPEG-TS, FLV και WMV/ASF αναγνωρίζονται από το περιεχόμενο. Η πραγματική δυνατότητα μετατροπής εξαρτάται και από τον codec μέσα στο αρχείο. Άγνωστα, αλλοιωμένα, κρυπτογραφημένα ή μη υποστηριζόμενα αρχεία επιστρέφουν συγκεκριμένο σφάλμα.

Η γρήγορη διαδρομή βίντεο χρησιμοποιεί Mediabunny/WebCodecs. Όταν δεν μπορεί να διατηρήσει εικόνα και ήχο, χρησιμοποιείται FFmpeg WASM στον browser. Το αρχικό αρχείο προσαρτάται μόνο για ανάγνωση με WORKERFS, αντί να αντιγράφεται ολόκληρο στη μνήμη WASM. Μετά τη μετατροπή επαληθεύονται μέγεθος, διάρκεια και παρουσία ήχου. Η ακύρωση τερματίζει τον worker. Οι βαριές μετατροπές εκτελούνται σειριακά και οι πόροι ελευθερώνονται μετά από κάθε αρχείο.

Τα `npm run dev` και `npm run build` προετοιμάζουν αυτόματα τα versioned αρχεία `public/codecs/`. Ο φάκελος παράγεται από τις κλειδωμένες εξαρτήσεις, παραμένει εκτός Git και αντιγράφεται στο τελικό `dist`. Τα εργαλεία φορτώνονται από το ίδιο site μόνο όταν απαιτούνται. Δεν χρειάζονται εξωτερικό CDN, SharedArrayBuffer ή πρόσθετα headers απομόνωσης. Το `NOTICE.txt` και η άδεια libheif συνοδεύουν τα παραγόμενα αρχεία.

Η παλιά διαδρομή `/api/video-transcode` διατηρείται μόνο για εγκαταστάσεις με native ffmpeg και πλέον απαιτεί διαχειριστή πριν διαβαστεί το σώμα του αιτήματος. Η εφαρμογή δεν την χρησιμοποιεί για μεταφορτώσεις Netlify.

Τα όρια της διαθέσιμης μνήμης/ισχύος της συσκευής εξακολουθούν να ισχύουν. Η αναγνώριση ενός container δεν αποτελεί εγγύηση υποστήριξης κάθε πιθανού codec, RAW παραλλαγής ή προστατευμένου περιεχομένου.
