# Στάδιο 2 — Διαχωρισμός δημόσιων και ιδιωτικών δεδομένων

Βάση: `e36597d4010f4ded93883dcf15ba3e2e44d2764a`. Branch: `codex/stage-2-public-private-2026-10-14`.

## Παραδοτέο

Η δημόσια εφαρμογή διαβάζει αποκλειστικά `publicCatalog`, `publicPortfolio` και `publicSettings/shop`. Το back office συνεχίζει να διαβάζει τα πλήρη `jewelry`, `portfolio`, `settings/shop` και το ιδιωτικό ιστορικό. Το `server/public-projection.ts` ορίζει ρητές λίστες πεδίων, χωρίς μεταφορά άγνωστων πεδίων ή επέκταση ιδιωτικών αντικειμένων στη δημόσια προβολή.

Οι εγγραφές καταλόγου περνούν από authenticated server gateway. Τα client SDK writes προς τον κατάλογο, τις προβολές και το ιστορικό απορρίπτονται στους υποψήφιους κανόνες του emulator, ακόμη και για διαχειριστή. Ο gateway διατηρεί τους τύπους Firestore, ελέγχει συγκρούσεις και αποθηκεύει το πλήρες προϊόν και τη δημόσια προβολή στην ίδια συναλλαγή. Σταθερό request ID και receipt αποτρέπουν διπλή εφαρμογή όταν χαθεί η απάντηση. Οι παραγγελίες ενημερώνουν απόθεμα και δημόσια προβολή στην ίδια συναλλαγή. Ο περιοδικός reconciler διορθώνει αποκλίσεις και αφαιρεί ορφανές προβολές· οι αποτυχίες καταγράφονται ως διαδρομές και δεν θεωρούνται επιτυχής συγχρονισμός.

Οι υπάρχουσες διαδρομές επεξεργασίας, batch, αντιγραφής, διαγραφής, γρήγορης πώλησης, σειράς, Vinted και undo/redo χρησιμοποιούν τον gateway. Η αντιγραφή διατηρεί τα πρόσθετα ιδιωτικά πεδία, αλλά δεν αντιγράφει δεσμεύσεις checkout. Excel διατηρεί την πλήρη ιδιωτική είσοδο. Το CSV διατηρεί τις παλιές στήλες και προσθέτει description, notes, internalNotes, review και πλήρες JSON. Τα περιστρεφόμενα backups επεκτάθηκαν με προβολές, ιδιωτικό ιστορικό/parts και journals· εξακολουθούν να μην είναι μόνιμο πλήρες backup.

## Δημόσια και ιδιωτικά πεδία

| Περιοχή | Δημόσια | Ιδιωτικά |
| --- | --- | --- |
| Προϊόν | name/title/subtitle, description, category/collection/status, dimensions/weight/condition/edition/badge, έγκυρες τιμές, απόθεμα και σειρά, δημόσιοι μετρητές, materials/colors, υπάρχουσες σημαίες αγοράς | notes, internalNotes, notesReview, κόστος, θέση αποθήκευσης, πηγές εισαγωγής, δεσμεύσεις, ιστορικό και κάθε άγνωστο πεδίο |
| Πολυμέσα | Μόνο επιλεγμένα δημόσια derivatives ή επιλεγμένα εξωτερικά δημόσια URLs | Πρωτότυπα, κρυφά αρχεία, όλα τα owned Storage URLs και tokens |
| Ρυθμίσεις | Συγκεκριμένα πεδία θέματος, hero, ανακοίνωσης, σειράς κατηγοριών, χρωματικών δειγμάτων και καθαρισμένο portfolioDesign | AI/config/customFields και μη επιτρεπόμενα εμφωλευμένα πεδία |
| Παραγγελίες | Δεν δημοσιεύονται στον κατάλογο | Πελάτης, διεύθυνση, snapshots, ειδοποιήσεις και κατάσταση παραγγελίας |

Η ακριβής λίστα βρίσκεται στον κώδικα προβολής, όχι σε γενικό `...product`. Υπάρχοντα `customInscription`, favorites/views και σύνδεσμοι αγοράς διατηρούνται ως υπάρχουσες δημόσιες δυνατότητες.

## Description και notes

Τα αρχικά `notes` και `description` διατηρούνται ακριβώς, χωρίς trim ή αυτόματη μεταφορά. Στην προβολή λεπτομερειών του προϊόντος στο back office υπάρχει χειροκίνητος έλεγχος δημόσιας εκδοχής και εσωτερικών σημειώσεων. Η έγκριση αποθηκεύεται ιδιωτικά με hash των δύο αρχικών κειμένων και χρήστη ελέγχου. Αλλαγή οποιουδήποτε αρχικού κειμένου ακυρώνει τη χρήση της προηγούμενης έγκρισης. Χωρίς έγκυρη έγκριση δημοσιεύεται μόνο το υπάρχον description· ποτέ αυτόματο fallback στο notes. Αυτό μπορεί να αφήσει προϊόν με notes αλλά χωρίς description χωρίς δημόσια περιγραφή μέχρι να ελεγχθεί.

## Κρυφά προϊόντα και αρχεία

`showInShop: false`, soft-deleted και deleted προϊόντα δεν παράγουν δημόσιο έγγραφο. Δεν υπάρχει fallback στον αρχικό στατικό κατάλογο όταν αποτύχει το δημόσιο query. Οι εναλλακτικές αναφορές imageUrl/images/src/image/videoUrl ελέγχονται μαζί με mediaList και originalUrl, με σύγκριση ταυτότητας owned αρχείου ανεξάρτητα από token.

Τα νέα uploads περνούν από `private-upload`: στον emulator αποθηκεύονται από τον server χωρίς Firebase download token, ενώ ο κώδικας παραγωγής προετοιμάζει σύντομο signed GCS write URL με προϋπόθεση νέας γενιάς. Το browser δεν χρησιμοποιεί πλέον Firebase getDownloadURL για upload. Οι υποψήφιοι Storage κανόνες απορρίπτουν απευθείας client uploads. Στην παραγωγή απαιτείται ξεχωριστή επαλήθευση IAM signing, CORS, ορίων μεγέθους και χρόνων upload πριν ενεργοποιηθεί η αλλαγή.

Τα derivatives παραμένουν ιδιωτικά στο Storage. Ο δημόσιος reader ελέγχει ότι το συγκεκριμένο immutable asset παραμένει στην τρέχουσα δημόσια προβολή και υποστηρίζει Range/HEAD χωρίς δημόσια cache. Αποτυχημένο draft ή παλιό URL κρυμμένου αρχείου απορρίπτεται ακόμη και αν η φυσική διαγραφή αποτύχει. Cleanup jobs επαναλαμβάνονται. Τα πρωτότυπα διατηρούνται ιδιωτικά για ιστορικό, αντιγραφές και backup· physical purge δεν εγκρίθηκε ούτε προστέθηκε.

Παλιές Firebase token αναφορές ανακλήθηκαν αποκλειστικά στα συνθετικά δεδομένα του emulator. Δεν ανακλήθηκε πραγματικό token. Περιεχόμενο που έχει ήδη κατεβεί από τρίτους δεν μπορεί να ανακληθεί. Εξωτερικά URLs ελέγχονται ως προς τη συμπερίληψη στη βιτρίνα, αλλά δεν ελέγχεται η πρόσβαση στον εξωτερικό πάροχο.
